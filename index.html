          Скан или PDF с ТАБ-станами распознаёт локальный сервис: он рендерит страницы в 300 dpi,
          находит 6-линейные станы и читает цифры ладов OCR. Признанный таб можно поправить руками
          и превратить в варианты аппликатуры. Файл никуда не отправляется — только на 127.0.0.1.
        


        

          Перетащите PDF сюда
          или нажмите, чтобы выбрать файл (application/pdf)
          
        


        

          
Локальный сервис не запущен — или браузер блокирует запрос

          
1. Запустите сервис одной командой из корня репозитория:

          
cd omr-service && ./run.sh

          
2. Если сервис уже запущен, но запрос не проходит: новые Chrome и Safari блокируют обращения со страницы https://… к 127.0.0.1. Разрешите доступ, когда браузер спросит («искать устройства в локальной сети»), либо откройте сайт локально:

          
python3 -m http.server 8080
# затем http://localhost:8080

          
Сервис слушает 127.0.0.1:8765. Нужны poppler (pdftoppm) и tesseract; подробности — в README, раздел «PDF → таб».

          OMR ошибается в ритме и иногда в высотах — проверьте список нот перед конвертацией.
          Audiveris не переносит ритм, размер и темп, а высоты на плохих сканах сдвигаются на полутон.
          Список ниже правится: так вы получаете верную мелодию, а не «как распозналось».
        
    

        
    
          
    
            
    1. PDF с нотами
    
            
    
              Страницы рендерятся в 300 dpi на вашем компьютере и распознаются локальным сервисом
              (Audiveris). Файл никуда не отправляется — только на 127.0.0.1.
              Для сканов ТАБ-табулатур — соседняя вкладка «PDF → таб».
            
    
            
    
              Перетащите PDF с нотами сюда
              или нажмите, чтобы выбрать файл (application/pdf)
              
            
    
            
            
    Одна страница ≈ 8–10 секунд. «1-3» — несколько страниц подряд.
    
          
    

          
    
            
    2. Или MusicXML
    
            
    
              Уже есть цифровой файл? MuseScore / Guitar Pro / Sibelius: «Экспорт → MusicXML».
              Принимаем .musicxml, .xml и .mxl — без сервиса и интернета.
            
    
            
            
    
          
    
        
    

        
    
          
    Локальный сервис не запущен — или браузер блокирует запрос
    
          
    1. Запустите сервис из корня репозитория:
    
          
    cd omr-service && ./run.sh
    
          
    2. Нужен Audiveris (OMR нот):
    
          
    brew install --cask audiveris
export AUDIVERIS_APP=/Applications/Audiveris.app
    
          
    3. Если сервис работает, а запрос не проходит, — Chrome/Safari блокируют обращения со страницы https://… к 127.0.0.1. Разрешите доступ в запросе браузера или откройте сайт локально:
    
          
    python3 -m http.server 8080
# затем http://localhost:8080
    
          
    Без Audiveris работает загрузка MusicXML — это второй способ, он всегда доступен.
    
          
        
    

        
    
        
    
        
    

        
    
          
    
            
    Распознанные ноты 
    
            
    
              
              
              
            
    
          
    

          
      

          

          
      
            Каждая нота правится: ↑/↓ — полутон, ⇑/⇓ — октава, ＋ — вставить ноту после, ✕ — удалить.
            Ноты вне диапазона гитары выделены красным.
          
      
          
      

          
      
            
            
            
            
            
          
      

          
      
          
      
        
      
      
      
    
      

    
      
      
      Ритм в табулатуре не хранится: переводится только высота нот. Аппликатура на гитаре неоднозначна, поэтому все варианты равноправны — выбирайте удобный. Лады 0–15, только гитара.
